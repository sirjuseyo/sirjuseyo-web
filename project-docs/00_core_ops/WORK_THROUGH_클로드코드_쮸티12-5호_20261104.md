- 워크스루 섹션마다 고유 ID 부여 (예: WT-001)

```

| 작업일 | YYYY-MM-DD, HH:MM |
| 작업자 | 쮸티12-5호 |

[문제 위치]
파일:
라인:

[증상(문제 설명)]

[원인]

[진단(수정 이유)]
```

- 처방에 전/후 코드 상세 기록
- 하나의 WT-ID에 추가 수정 발생하면, 덮어쓰는 것이 아니라 이어서 추가해야 함
