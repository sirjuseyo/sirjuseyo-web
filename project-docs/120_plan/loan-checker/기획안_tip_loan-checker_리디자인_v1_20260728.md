## 1. 목적

대출 가능성 검사기는 이벤트 페이지가 아니다. **앱이 아직 담지 못한 실제 운영 절차(옵션·이력·상태·좌석·미션 포인트)를 신청 전에 미리 굴려보는 시뮬레이터**이며, 불완전한 앱 플로우와 실제 오프라인 운영 플로우 사이의 간극을 메우는 브리지다.

또한 검사기는 앱 To-Be의 **기준 파일**이다 (신청단계 기획안 §12가 검사기 3개 파일을 To-Be 앱 선택 항목의 기준으로 명시). 따라서 이번 작업은:

- 구조·선택 항목·계산 체계는 보존하고,
- 톤·비주얼만 "노멀·심플·담백"으로 정리하며,
- ~~기획안이 명시한 데이터 보정(4,500 일괄 등)을 별도 Phase로 수행한다.~~ (→ Phase B 취소. §12 참조. 4,500P 변경은 이미 반영 완료.)

디자인 철학: **멋드러지게 = 장식을 걷어낸 자리를 여백·타이포·위계로 채워, 담백함이 의도된 세련으로 읽히게 한다.**

## 4. 이모지 정책 (판별 규칙)

> **상품·운영 스크립트에서 온 이모지는 '콘텐츠' → 유지. 웹 페이지가 자체적으로 붙인 장식 이모지는 '장식' → 제거.**

| 구분 | 대상 | 처리 |
|---|---|---|
| 콘텐츠 (유지) | 상품명(7️⃣🈷️🏖️💦), 등급 뱃지(💎🥇🥈🥉🎁), 혜택 서술 내 표현(🌟, 🐶널널, 🐶빡셈, 🐝배려, 😻PASS — 운영 스크립트 유래), 포인트 기호(🅿), 체크리스트 상태(✅ ☑️ ⓵~⓹), 번호(❶❷❸) | 유지 |
| 장식 (제거) | 라벨 태그(🏷️), 섹션 제목 아이콘(📅 🧑‍💼 🧮 🧾 📋 ℹ️ ⚠️ 🧩 💸 🏦 🟰 🛢️ ➕ 🗓️ 🎟️), placeholder·옵션 값 장식(🔍 💰 🔥 👍 🎮 🍞 🙈 💪 💯 🎉 📡 🙆 😤 📤 🫡 🫣 🆔 🪪 📱), 항목 앞머리 아이콘(👑 🍀 🚀 😰 ☝️ ✌️ 😓 ✊ 🪄 ✨), 경고 과잉(⚠️⚠️ 🚨 ☢️ ❗️ 💬), 기타(🕒 👀 🙏😘) | 제거 |

세부 기준 (앱 To-Be §14.3 확정 목업과 동일):
- 옵션 가이드에서 **항목 앞머리 아이콘(👑🍀🚀😰)은 제거**, 괄호 안 **혜택 표현(포인트 적립 🐶빡셈 등)은 유지**.
- 혜택 타이틀 이모지는 ✨ → **🌟로 통일** (운영 스크립트 원형 `🌟 {옵션}의 가장 큰 혜택`).
- 경고는 이모지 반복 대신 **경고 박스 스타일**로 표현. ⚠️는 블록당 최대 1개.

### 5.7 구현 주의 (필수)

1. **option value = 표시 텍스트 결합**: ④ 이력·상태뿐 아니라 **⑤의 모든 셀렉트도 `value` 속성이 표시 텍스트와 동일**하다 (예: `value="신청했어."`). app.js·인라인 스크립트에서 해당 문자열을 참조하는 모든 지점(LOAN_CONFIG 키, 분기 조건)을 동시 변경하거나 표시 전용 레이어를 분리할 것. 변경 전후 동일 조합 → 동일 포인트 회귀 확인 필수.
2. **JS 주입 문자열 3곳 수정**: 인라인 스크립트의 `santaApplyLabel`("🏷️ … 신청했어?"), `step1`, `resultInfoHeader` 등 month-config 조합 문자열도 §5.3 문구로 교체.
3. **오타 수정**: app.js `LOAN_OPTION_STATUS_TABLE`의 "블랙찬스 티캣" → "블랙찬스 티켓" (키 참조 동반 확인).
