## 1. 프로젝트 개요

### 목적
- 구글 플레이 / 앱스토어 심사용 개인정보 방침 페이지 운영
- 기존 노션 + 우피 기반 페이지 → **순수 HTML로 전환**
- 깃 관리자(Ser7호)를 통해 AWS에 배포

### 배포 환경
- **배포 URL:** `https://privacy.sirjuseyo.com/privacy/`
- **인프라:** AWS (Ser7호 설정 완료)
- **전달 방법:** 깃 관리자에게 HTML 파일 전달 → AWS 반영

### 산출물
```
sirjuseyoWeb/
└── privacy/
    └── index.html     ← 최종 산출물 (단일 HTML 파일)
```

## 4. UI 구성 방식

### 7개 문서 탐색 방식
원본 스크린샷 기준: 상단 목록 리스트에서 항목 클릭 → 해당 문서로 스크롤 이동

### "Privacy" 뱃지
각 항목 우측에 붉은 계열 `Privacy` 뱃지 표시

### 아이콘
