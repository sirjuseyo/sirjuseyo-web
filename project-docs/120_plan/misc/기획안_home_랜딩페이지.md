- 빠른 제작 우선 → 반응형/최적화는 추후 리팩토링
- 네비게이션 구조는 전체 사이트맵 확정 후 역으로 추가
- 앱 스토어 링크는 실제 URL 확인 후 교체 (임시 `#` 사용)
- SEC-04, SEC-06 dark 섹션: SVG 네온 곡선은 CSS `border-radius` + `rotate` 또는 인라인 SVG `<path>`로 구현
