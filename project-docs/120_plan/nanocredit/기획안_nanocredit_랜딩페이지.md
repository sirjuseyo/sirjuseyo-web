### [SEC-10] Use Case — "특히 이렇게 쓰면 끝이에요."
- **배경**: 흰색
- **레이아웃**: 좌측 텍스트 + 우측 앱 스크린샷
- **헤드라인**:
  ```
  특히 이렇게 쓰면
  끝이에요.
  ```
  - `끝이에요.` → 노란색 강조
- **서브 텍스트**: `어차피 물건을 구매한다면, 써주세요. 포인트 적립소에서 구매해요.`
- **3가지 혜택 (아이콘 + 텍스트)**:
  1. 💰 적립된 포인트로 **빌린 돈을 갚을 수 있어요.**
  2. 👤✓ 구매 이력으로 **대출 승인될 확률이 높아요.**
  3. 🔴↑ **한도 상향의 기회가 생겨요.**
- **우측 이미지**: 포인트 적립소 앱 화면
- **참고 이미지**: `sjy_web_home (1).png`
